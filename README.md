# Golf Course Finder

A small web application for searching, filtering, and sorting golf courses.

## Features

- Live course search
- Country and hole-count filtering
- Multiple sorting options
- Debounced live-search input
- Request cancellation
- Loading, empty, success, and error states
- Responsive interface

## Built With

- HTML
- CSS
- JavaScript
- Vite

## Running Locally

npm install
npm run dev

## Production Build

npm run build
npm run preview
